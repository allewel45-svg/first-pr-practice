# First PR Practice

A tiny playground repo for practicing the GitHub PR workflow: branch, commit, push, open a PR, merge.

## What's here

- `greet.py` — a small greeting utility with a couple of unit tests.

## Usage

```bash
python greet.py Ada
```

Prints a friendly greeting to the console. Omit the name to greet `World` by default. This repo is intentionally minimal so its easy to find small, safe improvements to practice with.

## Running tests

```bash
python -m unittest test_greet.py
```
